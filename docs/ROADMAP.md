# Roadmap — La Coffee Gelateria

Site institucional + cardápio digital (QR code das mesas) + painel admin.

## Stack

- Next.js + Tailwind CSS
- Supabase (banco, login, fotos) — a partir da Fase 3
- Vercel (hospedagem gratuita)
